# Commitplan bis 0.4.0

Der initiale Repository-Stand besitzt bereits eine gegliederte Historie.
Für die verbleibende Abnahme von 0.3.1 werden voraussichtlich benötigt:

1. `chore(deps): commit generated NuGet lock files`
2. `fix(build): resolve first clean-machine compiler findings`
3. `test(ci): verify Windows and Ubuntu workflows`
4. `docs(status): close milestone 0.3.1`

Danach beginnt 0.4.0 mit eigenständigen Commits für Presentation Core,
WinForms-Host, MailKit-Adapter, POP3-Verbindungstest und Abrufmodi.
